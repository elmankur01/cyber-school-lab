## 🛠️ 3. Стек технологий

* **Фронтенд:** React 19, TypeScript, Vite
* **Стилизация:** Tailwind CSS, Glassmorphism, Neon Glow effects, Lucide React Icons
* **Анимации & Эффекты:** Canvas Confetti, CSS Keyframe Animations

* **Хостинг & CI/CD:** Render Static Site (авто-билд по push в `main`) via `render.yaml`

## 🧠 6. Ключевые игровые механики

1. **Экономика опыта (XP):**
   * Прохождение обычного уровня: `+30..+50 XP`
   * Победа над Вирусом-Боссом: `+200 XP` + Секретный чип знаний
   * Победа в PvP Дуэли: `+100 XP` + очки за оставшееся время
   * Квесты дня: `+80..+120 XP` за каждое задание
2. **Серия тренировок (Стрик 🔥):**
   * Отслеживается по дням в `localStorage` (`cyber_lab_last_active_date`).
   * Защита стрика через «Заморозку» (Streak Freeze).
3. **Кибер-Магазин (Кастомизация):**
   * Купленные неоновые рамки сохраняются в профиле и динамически светятся вокруг аватара в шапке, дуэлях и таблице лидеров.
